# 부록 — 한 장 요약

## 1장 (예고편) = 신뢰

> 변화가 온다(비트코인·핀테크). 혁신엔 빛과 그림자(2008 교훈). 핵심은 **신뢰 3종**(발행기관·가치·시스템) — 민간은 다 무너질 수 있어 정부가 최후 보루(CBDC·프로젝트 한강). BIG 질문: **점진적 개선인가, 진짜 혁명인가?**

## 2장 (본편) = 기준선

> 화폐 3기능(척도·교환·저장)으로 새 화폐를 채점. 내부화폐(은행 창출) vs 외부화폐(현금). 금본위제 = 스테이블코인 준비자산의 뿌리. 금융의 핵심 = **금융 중개**(저축·신용·위험관리). 신뢰의 진화: **담보 → 중앙은행 → 블록체인.** → **정부가 "어디에 선 그을까" 골머리.**
