# 부록 — 한 장 요약

## 1장 (예고편) = 신뢰

> 변화가 온다(비트코인·핀테크). 혁신엔 빛과 그림자(2008 교훈). 핵심은 **신뢰 3종**(발행기관·가치·시스템) — 민간은 다 무너질 수 있어 정부가 최후 보루(CBDC·프로젝트 한강). BIG 질문: **점진적 개선인가, 진짜 혁명인가?**

## 2장 (본편) = 기준선

> 화폐 3기능(척도·교환·저장)으로 새 화폐를 채점. 내부화폐(은행 창출) vs 외부화폐(현금). 금본위제 = 스테이블코인 준비자산의 뿌리. 금융의 핵심 = **금융 중개**(저축·신용·위험관리). 신뢰의 진화: **담보 → 중앙은행 → 블록체인.** → **정부가 "어디에 선 그을까" 골머리.**

## 3장 = 핀테크의 깊이

> 핀테크의 특징은 **'깊이'** — 상품 개선을 넘어 금융의 기반 구조를 바꾼다. 모바일머니(엠페사)·디지털은행·P2P·인슈어테크·핀테크결제(알리페이·인디아스택)·로보어드바이저. 혁신은 **신흥국(중국·인도)이 주도**하고, 은행 점유율을 뺏기보다 **시장을 확장(금융포용)**. 단, 검증 안 된 모델·프라이버시 침해 위험 상존.

## 4장 = 비트코인

> **"신뢰를 기관이 아니라 기술로"** — 2008 금융위기 불신에서 탄생. 블록체인(분산장부)·해시·공개키/개인키·머클트리·작업증명(PoW)으로 구현. 최대 2,100만 개·반감기. 장점(신뢰성·투명성·보안성·불변성) vs 한계(변동성·확장성·수수료). **불변성의 양날**: 되돌릴 수 없고 잃으면 못 찾는다 → 현재는 결제수단보다 **디지털 금**.

## 5장 = 암호화폐의 확산

> 비트코인 대안들: PoS(지분증명)·**스테이블코인(테더의 준비금 논란)**·프라이버시코인(모네로·지캐시 ZKP)·스마트계약·ICO(투기·사기)·**리브라→디엠**(규제 반발로 좌초)·DeFi·밈코인. 결론: **어떤 코인도 중앙은행 화폐를 대체할 안정성·효율성·프라이버시 조합을 못 냈다.** 하지만 페이스북의 시도가 중앙은행을 각성시킴.

## 6장 = CBDC란?

> 중앙은행이 발행하는 디지털 명목화폐. **도매(은행간) vs 소매(대중)**, 소매는 e머니·계정기반·공식암호화폐. 발행 동기: **결제 백스톱·금융포용·통화주권**. 통화정책 확장(마이너스 금리). 단점: **혁신 억압·은행 탈중개·뱅크런·프라이버시 소멸**. → "국가가 어디까지 개입하나"의 문제. 대부분 **현금 보완**(대체 아님)으로 설계.

## 7장 = CBDC의 이륙

> 실제 사례. **중국(디지털 위안)·스웨덴(e-크로나)** 모두 **2단계 구조(중앙은행 발행 → 상업은행 유통) + 허가형 블록체인**으로 수렴 = **프로젝트 한강의 모델**. 소국의 "공식 암호화폐"(베네수엘라 페트로·마셜제도 소버린)는 **"통화의 신뢰는 그 뒤 정부의 신뢰를 못 넘는다"**는 교훈만 남김.

## 8장 = 국제통화·달러패권

> **거꾸로 흐르는 돈**(신흥국 → 미국): 안전자산(미 국채) 수요 때문. 달러 패권의 근거는 기술이 아니라 **네트워크 효과 + 시장의 깊이 + 제도적 신뢰** → **기술로 복제 불가**. 디지털 위안은 국내 결제 도구이자 **제재 우회로**, 기축통화 도전자는 아니다(자본통제 유지). **SDR**은 민간이 안 써서 대안이 못 됨 → "달러 우위 + 점진적 다극화". 진짜 리스크는 소국의 **디지털 달러화**(통화주권 상실). 후속: 스테이블코인의 99%가 달러 페그 → **달러의 경쟁자가 아니라 유통 채널**이었다(GENIUS Act 2025).

## 9장 = 중앙은행의 시련

> 임무는 팽창(물가 → 금융안정 → 결제 운영자), 수단은 부족. 통화정책 **전달경로 약화**, 프로그래밍 가능한 돈은 사실상 **재정정책** → 중앙은행의 **정치화**. 새 취약점: 스테이블코인 런·디지털 뱅크런·탈중개·빅테크 집중·DeFi 레버리지·사이버. 규제 원칙 = **"같은 활동, 같은 위험, 같은 규제"** → 금지가 아니라 **규제 안으로 끌어들이기**. 후속: 테라(2022)·FTX·SVB→USDC 디페깅(2023)으로 경고가 전부 실증됨 → MiCA·GENIUS Act·국내 2단계 입법, **예금토큰 vs 원화 스테이블코인** 노선 경쟁.

## 10장 = 미래 전망 + IBK 적용안

> 사라질 것 = **현금**(단 완전히는 아님, 익명성 상실이 대가). 남을 것 = **중앙은행 화폐·은행**(CBDC는 2단계), 달러 패권, 디지털 금으로서의 비트코인. 진짜 바뀔 것 = **금융 중개**(결제비용 붕괴·중개의 모듈화·프로그래밍 가능한 돈). 그림자 = 탈중앙의 역설(집중), 프라이버시 소멸, 감시국가, 새로운 배제, 사이버 단일 장애점.
>
> ⭐ **BIG 질문의 답**: 화폐의 **본질(신뢰)은 불변**, **형태는 진화**, **금융 중개는 혁명** → **"혁명은 화폐에서가 아니라 은행에서 일어난다."**
>
> ⭐ **IBK 적용안**: 예금토큰 우선 / 원화 스테이블코인은 입법 후 대응 / 알고리즘형 회피. 유스케이스 = **B2B 정산·에스크로, 정책자금 바우처, 무역결제, 공급망금융, AI 에이전트 결제**. 역량 = 24/7 인프라·키관리·RegTech·ZKP·접근성 UX.

## 부록 = AI 에이전트 × 스테이블코인 (2025 후속)

> AI 에이전트가 **스스로 결제**하는 자율경제의 화폐로 스테이블코인 부상. 전통결제의 한계(지연·고비용·인간중심)를 극복(수백ms·초저비용·계정불필요). 연결고리 = **x402 프로토콜**(방치된 HTTP 402 코드 부활, Coinbase 2025.5). PPU·M2M 경제로 확장. → 책이 멈춘 2021년 **"그 뒤 이야기"**.
