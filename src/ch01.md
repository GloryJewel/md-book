# 1장 — 미래를 향한 경주

> **1장의 정체:** 본편이 아니라 **예고편**이다. 뒤에 나올 모든 주제를 한 번씩 던져놓는 도입부.
> **1장을 한 단어로:** **신뢰(信賴)**

---

## 1. 도입 — "현금의 종말"

- 스웨덴 릭스방크(세계 최초 중앙은행) 부총재: **"2030년 이전에 마지막 지폐가 사라진다"**
- 흥미로운 대칭: **중국**(천 년 전 최초의 지폐) + **스웨덴**(최초의 중앙은행) → 둘 다 다시 디지털 화폐 선두
- 메시지: 우리가 아는 '돈'의 속성이 **근본적으로 바뀌는 변곡점**

---

## 2. 변화의 두 축

| 축 | 성격 |
|---|---|
| **비트코인/암호화폐** | 화려하지만, 본질은 '기반 기술' |
| **핀테크** | 덜 화려하지만 **더 중요한** 혁명 |

### 혁신의 빛과 그림자 (2008 금융위기 = 복선)

새 금융상품 + 규제 완화 → 위기로 이어진 패턴:

- **① 위험 과다 추구** (개별의 문제): 싼 빚 + 보너스 욕심 → 무리한 베팅
- **② 위험 집중** (연결의 문제): 분산 없이 한곳(리먼)에 몰빵 → 연쇄 도산(전염)

> 저자의 진짜 메시지: **"모든 금융 혁신엔 빛과 그림자가 있다. 새 기술(비트코인·스테이블코인)도 위험-편익을 따져야 한다."**

#### ③ 스테이블코인 연결

> 2008년 리먼이 준 교훈을, **2022년 테라·루나**가 코인 시장에서 그대로 반복했다.
> 안전하다 믿었던 코인이 → 위험이 집중돼 있었고 → 한순간에 연쇄 붕괴.
> 그래서 스테이블코인엔 **준비자산 규제**가 생겼다.

> **[현재 한국 사례]** 코스피가 삼성·반도체 원툴로 상승 → 위험이 한곳에 쏠린 구조.
> "붕괴한다"가 아니라 **"위험이 한쪽에 쏠려 있다"**가 정확한 표현. (구조 설명, 투자 조언 아님)

## 3. 거꾸로 흐르는 돈 (2장 예고이자 1장 배경)

```
정상: 부유한 나라 → 가난한 나라 (여유 있는 쪽이 투자)
실제: 중국(저축) → 미국(무역적자 메움)  ← 역기능
```

- 중국發 자금이 미국에 넘침 → 금리 낮고 돈 흔함 → **"투기에 기름"** → 2008 위기
- 그 뒤 유로존 부채위기 → 교훈으로 **규제 강화**

#### ③ 스테이블코인 연결 (사용자의 핵심 통찰)

> **"스테이블코인이 돈을 더 빨리 흐르게 하면 — 더 취약한 거 아닌가?"** → **맞다. 양날의 검.**
>
> - **그림자:** 24시간 글로벌 뱅크런, 국경 통제 무력화, 전염 속도↑, 규제 사각지대
> - **빛:** 투명성(숨은 연결↓), 저비용 송금(7%→1%), 금융포용(은행 없는 17억 명)
>
> 결론: **"위험하니까 막자" ❌ → "위험하니까 안전장치 걸고 쓰자" ✅** = 규제(준비자산 100% / 발행한도 / 트래블룰)

> **[발표 하이라이트]** 이 질문을 청중에게 그대로 던진다. → 1장(혁신의 양면성)으로 한 바퀴.

## 4. 중앙은행의 고민 — 신뢰 · 프라이버시 · 통제

### 신뢰 3종 (★ 1장의 메인 프레임)

| 신뢰 | 무너지면 | 사례 |
|---|---|---|
| **① 발행기관 신뢰** | 디지털이어도 소용없음 | "신뢰는 발행기관을 못 넘는다" |
| **② 화폐 가치 신뢰** | 돈이 휴지가 됨 | 쿠빌라이칸 지폐 남발 / 테라·루나 / 짐바브웨 |
| **③ 결제 시스템 신뢰** | 통로가 멈춰 경제 정지 | FTX 인출중단 / 뱅크런 |

> 민간은 ①②③ 다 무너질 수 있다 → **정부(중앙은행)가 신뢰의 최후 보루** → CBDC / 프로젝트 한강

#### "결제가 멈춘다"의 두 경우

- **기술적 정지**: 서버 다운·회사 파산 (예: FTX 인출 막힘)
- **신뢰 붕괴**: 서버는 멀쩡한데 다 같이 빼려다 마비 (뱅크런)

> 민간은 위기 때 멈출 수 있지만, 정부 시스템엔 **중앙은행이라는 최후 방어선**이 있다.

### 한국 IMF(1997) 비유 — 한국 청중용 강력 카드

> 1997 IMF: 외국 단기자금이 동시에 탈출 → 달러 부족 → 환율 폭등 → 구제금융 (= 나라 단위 뱅크런)
>
> 1997(외국자본) · 2008(투자자) · 2022 테라(사용자) → **"다 같이 동시에 탈출하면 어떤 시스템도 못 버틴다"**

### 자유 vs 통제의 줄다리기 (★ 발표 클라이맥스)

혁신의 역설 3종:

| 약속(빛) | 역효과(그림자) |
|---|---|
| 탈중앙화 — 강자 이점 약화 | **네트워크 효과** — 1등이 다 먹음 (구글·페북) |
| 금융 민주화 — 빈곤층 접근 | **격차 심화** — 지식·접근성 있는 부유층에 집중 |
| CBDC — 민간 독점 통제 | **과잉 통제** — 정부의 시민 감시·통제 도구(독재) |

> **"통제권을 가져오는데… 너무 가져와서 권력을 쥐게 된다."** (사용자 정리)

#### ⭐ "긴장 = 사업 기회"

> 프라이버시 ↔ 추적가능성은 영원한 시소. 현금=100% 익명, CBDC=100% 추적.
> **이 긴장을 푸는 곳에 사업이 있다:**
> - **영지식증명(ZKP)** — "범죄자 아님은 증명하되, 신원·금액은 안 밝힌다"
> - 프라이버시 보존형 CBDC · RegTech(규제 자동 준수) · 금융소외층 UX
>
> **IBK시스템이 들어갈 자리가 바로 여기다.** (9주차 자유발표 주제로도 적합)

## 5. 추적·익명 오해 — 통념 뒤집기 (4주차 선행)

> 흔한 오해: "코인 = 익명 = 추적 불가" → **정반대다.**

- 퍼블릭 블록체인 = 모든 거래가 **영구 공개** = **은행보다 더 투명**
- 정확히는 익명(anonymous)이 아니라 **가명(pseudonymous)**: 지갑주소=닉네임, 행적은 다 공개. 실명만 연결(KYC·체인분석)하면 평생 거래가 드러남
- 추적 사례: 미국이 **2016년 해킹 코인을 2022년에 추적·회수** (6년 전 거래도 장부에 남아 있음)
- 예외 = 프라이버시 코인(모네로·지캐시) → 규제당국이 싫어해 거래소 퇴출

### "누가 보느냐 = 누가 통제하느냐" (블록체인 종류)

| 종류 | 누가 보나 | 예시 |
|---|---|---|
| **퍼블릭** | 전 세계 누구나 | 비트코인, 이더리움 |
| **프라이빗** | 허가받은 기업만 | 기업 내부 체인 |
| **컨소시엄** | 참여 기관들만 | **프로젝트 한강** |

- 비판: "프라이빗 = 비싼 데이터베이스 아니냐" (운영자가 장부 수정 가능 → 신뢰 출처가 기술→운영주체로)
- 금융권이 프라이빗/컨소시엄을 쓰는 이유: 고객 프라이버시 + 규제 준수 + 기관이 신뢰 보증
- 하이브리드: USDC는 퍼블릭(이더리움)이지만 발행사 Circle이 KYC·동결 권한 보유

## 6. 리브라 → 메타 2026 (책에 없는 후속)

```
2019 페이스북 리브라 발표 → 2020 Diem 개명·축소
→ 2022 매각/종료 (규제 반대 + 파트너 이탈로 좌초, 정식 출시 못 함)
→ 2026.4 메타 복귀!
```

| | 리브라 (2019, 실패) | 메타 (2026, 복귀) |
|---|---|---|
| 방식 | **직접** 코인 발행 | 남의 코인(USDC) **갖다 씀** |
| 규제 | 정면충돌 → 좌초 | GENIUS Act 후 합법 테두리 내 |
| 파트너 | 직접 다 하려 함 | Stripe·Circle에 위임 |

> **핵심 교훈:** 규제를 **이기려다 죽었고**(리브라), 규제에 **순응하니 살아났다**(2026 메타).
> 화폐는 아무나 못 만든다(신뢰·규제) → 그래서 한국도 **은행·한국은행 주도**(프로젝트 한강).

## 7. 1장 마무리 → 2장 연결

> 1장 마지막: **"판단하려면 먼저 기초(화폐 개념)를 알아야 한다."** → 2장 예고
>
> 저자의 BIG 질문: 이 변화는 **① 점진적 개선**인가 **② 진짜 전환**인가?
> → 판단하려면 잣대가 필요하다. 그게 **2장**이다.

### 책 ↔ 프로젝트 한강 대응표

| 책(화폐의 미래) | 프로젝트 한강 실물 |
|---|---|
| 화폐의 3기능 | 예금토큰 = 결제 + 1:1 가치 묶음 |
| 화폐 형태 변화 | 제조-발행-유통-환수-폐기를 블록체인으로 |
| CBDC 도매/소매 | 기관용 디지털화폐(도매) + 예금토큰(소매) **2층** |
| 신뢰 | 한국은행 발행 → 국가 신뢰 이식 |
| 프로그래밍 가능 화폐 | 디지털바우처, 국고금 집행, 스마트계약 |
| 책 마지막장(AI·미래) | 한강 2단계: AI에이전트 결제 + 토큰화 증권 |
