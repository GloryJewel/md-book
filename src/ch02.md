# 2장 — 화폐와 금융의 기초

> **2장의 정체:** 예고편(1장)에 이은 **본편**. "화폐란 무엇인가"의 기초·용어 정리.
> **2장을 한 단어로:** **기준선(baseline)** — 현재 금융을 재는 잣대를 그린다.

---

## 여는 인용문

> *"화폐는 공정하게도, 노예제처럼 불공정하게도 분배할 수 있는 힘이다."*
> — 영국 총리 **글래드스턴**의 말로 전해짐 *(책의 "알렉산더"는 오류로 추정 → 발표 시 출처 생략 또는 "글래드스턴")*

> 메시지: 화폐는 단순한 거래 도구가 아니라 **권력**이다. **어떻게 설계하느냐**가 사회의 정의를 결정한다.
> → 그래서 스테이블코인·CBDC를 **누가, 어떻게 만드느냐**가 중요하다.

---

## 1. 화폐의 3기능 + 신뢰의 근거

| 기능 | 뜻 |
|---|---|
| **가치척도** | 가격을 재는 자 ("이건 3,000원") |
| **교환수단** | 거래에 쓰임 |
| **가치저장** | 보관해도 가치 유지 |

### ★ 3기능 채점표 (킬러 슬라이드)

| | 교환수단 | 가치척도 | 가치저장 |
|---|:---:|:---:|:---:|
| 원화(현금) | ⭕ | ⭕ | ⭕ |
| 비트코인 | △ | ❌ | △ |
| 스테이블코인 | ⭕ | ⭕ | ⭕ |
| 예금토큰 | ⭕ | ⭕ | ⭕ |

> **한방 설명:** 비트코인은 가치척도·저장에서 실격 → 그래서 안정적인 **스테이블코인**이 등장.

### 무엇이 화폐를 뒷받침하나 — 금본위제

- 외부화폐 신뢰가 깨지면 경제 마비 → 옛날엔 **금·은으로 뒷받침**(금본위제) = "중앙은행 손을 묶어 돈 못 찍게"
- 딜레마: 신뢰는 ⭕지만 위기 때 돈을 못 풀어(유연성 ❌) → 결국 **명목화폐(fiat)**로

> **⭐ 킬러 포인트:** **스테이블코인 = 디지털 금본위제.** (1달러 준비자산으로 코인 1개를 뒷받침)
> 테라는 금 없이 알고리즘만으로 → 붕괴 → 이게 **"준비자산 100% 보관"** 규제의 뿌리.

## 2. 내부화폐 vs 외부화폐 (★ 실무 직관 강점)

### 내부화폐 = 민간은행이 "창출"

> 은행은 대출할 때 있던 돈을 **옮기는 게 아니라**, 키보드로 새 예금을 **만든다**("무에서 유").

- 통념 교정: "예금 받아야 → 대출" ❌ → **"대출이 예금을 창출"**도 함 (둘 다 일어남)
- 은행만의 특권 + 규제(지급준비금·자본)로 통제

### 복식부기 = 계정계 대사와 같은 원리

```
자산 = 부채 / 차변(왼쪽) = 대변(오른쪽) / "나간 돈 = 들어온 돈"
```

> **⭐⭐ 실무 연결 (발표 차별화):**
> 대사가 필요한 이유 = **장부가 여러 개라서.**
> 블록체인 = **단일 장부**라 애초에 대사 불필요.
> 단, 블록체인 ↔ 기존 시스템(계정계) **사이**는 여전히 연계·대사 필요 (5주차 API 연계) → **6주차 정산/대사 복선.**

### 외부화폐(현금)의 특별함

- 보유자에겐 자산, 중앙은행 장부엔 부채 (단 갚을 의무 없어 **사실상 무위험**)
- **민간 부문 시점:** 내부화폐는 자산↔부채 상쇄 = 0, **외부화폐만 순자산**으로 남음
- 위기 때 예금 빼서 현금 쥐려 함 = **뱅크런의 본질**

| | 누구의 부채 | 위험 |
|---|---|---|
| 내부화폐(예금) | 민간은행 | 그 은행 망하면 위험 |
| 외부화폐(현금) | 중앙은행 | 사실상 무위험 |
| **CBDC** | 중앙은행 (디지털) | 가장 안전 |
| **스테이블코인** | 민간 발행사 | 가장 위험 → 준비자산 규제 |

## 3. M0 / M2 — "이제 돈 = 대부분 예금"

| 기호 | 무엇 |
|---|---|
| **M0** | 현금 (외부화폐) |
| **M1** | M0 + 즉시 인출 예금 |
| **M2** | M1 + 정기예금 (내부화폐 포함, 넓은 돈) |

- 현금(M0) 비중 급감 → 돈의 대부분은 **은행이 만든 예금**
- 의미: ① 돈 개념을 넓혀야 ② 그 돈을 만드는 **은행이 핵심**인데, 새 기술이 이를 흔든다

> **③ 스테이블코인 연결:** 코인이 예금을 대체 → 은행의 화폐 창출 약화 → 통화정책이 흔들림.
> = **중앙은행이 스테이블코인을 경계하는 핵심 이유.**

## 4. 금융 시스템의 핵심 기능

> 결국 = **저축 + 신용(대출) + 위험관리** → 한 단어로 **"금융 중개"**. 중개가 잘 되는 나라 = 발전한 경제.

### ① 저축 → 생산적 투자 전환 (대출)

> **사용자 해석:** 대출 = **"미래를 사는 일"**(시간 이동) + **"썩는 가치를 저장해 생산적으로"**(농작물 비유)
> **책 핵심:** 잠자는 돈을 깨워 **경제를 키운다(생산적)**. 남는 곳 → 필요한 곳.

### ② 변동성 vs 위험 관리 (보험)

- **변동성** = 예상되는 출렁임(계절) / **위험** = 예측 못 할 사건(화재)
- 보험 = ① 위험 풀링(여럿이 나눠 짊어짐) ② 모은 돈 굴려 경제 순환 ③ 개인이 비상금 안 쟁여도 됨(죽은 돈 → 일하는 돈)
- ③ 블록체인: **파라메트릭 보험**(조건 충족 시 자동 지급)

### ③ 다각화로 위험 수용

- 분산 가능해야 모험(아마존)에 투자 → 혁신
- **비체계적 위험**(개별 기업, 분산으로 제거 ⭕) vs **체계적 위험**(시장 전체, 분산해도 ❌)
- "좋은 금융 시스템 = 모험에 돈 댈 수 있는 시스템"
- ③ 블록체인: **RWA 토큰화** = 분산 기회 극대화 (7주차)

#### 헤지 — 용어 함정 (★)

> **"헤지(행위)"** = 위험 방어 우산. 풋옵션 = "정한 가격에 팔 권리"(하한선). 비용 ≈ 자산의 2~5%/3개월.
> **"헤지펀드"** = 이름만 헤지, 실제론 고수익 노리는 **공격적 투기**.
> → **같은 단어, 정반대 뜻.** (헤지펀드는 1949 초창기 취지에서 이름만 남음)

### ④ 거시 다각화 + 금융 민주화의 한계

- 나라도 다각화 필요: 사우디(원유 원툴) vs 캐나다(다양)
- 글로벌 분산 기회가 **큰손에게만** 열림 (금융사가 서민 외면 = 편해서가 아니라 **고정비용 대비 수익이 안 나서**)

> **⭐ 블록체인의 명분:** 폰만으로 전 세계 자산 접근 + 수수료 0 + 토큰화로 쪼개기 = **금융 민주화 실현.**
> 개발도상국이 더 적극 쓰는 이유. (1장 "핀테크는 개도국 혜택 더 큼" 회수)

## 5. 결제 시스템 3종

| 종류 | 누가 | 예시 |
|---|---|---|
| **소매(retail)** | 개인·가게 | 카카오페이, 카드 (이미 편함) |
| **도매(wholesale)** | 은행 ↔ 은행 | 한은금융망 — 안 보이는 뒷단 (= 대사/정산) |
| **국경 간(cross-border)** | 나라 ↔ 나라 | 해외송금 — 중개은행 여러 개, 2~5일, 비쌈(SWIFT) |

> **절의 의도:** 국내는 1초인데 **국경만 넘으면 며칠/비쌈** = 가장 비효율 → **여기가 스테이블코인·CBDC의 최대 전장.**
> 발표 멘트: *"국경만 넘으면 왜 갑자기 후진국이 되는가?"*
> (1장 "거꾸로 흐르는 돈" 회수 / 한강도 도매+소매 매칭)

## 6. 그림자금융 + 금융포용

### 그림자금융(shadow banking)

> 불법(음지)이 아니라 **"은행 규제 밖"**에서 은행 같은 일을 하는 합법 금융 (헤지펀드·사모펀드·MMF). 안전망 없음 → 2008 위기가 이 그늘에서 터짐.

### 금융포용 (★ 사용자 프레임)

> **한국은 금융지식이 깊어서가 아니라 "인프라가 좋아서" 간접적으로 다 누린다.** (카카오페이 원리 몰라도 써짐)

- 1단계 **접근**(한국 완료) vs 2단계 **활용**(한국도 격차 남음). 개도국은 1단계부터 막힘 (전 세계 14억 명 계좌 없음)
- 한국 사각지대: 신용부족자→사채, 고령층→디지털 소외

> **⭐ 발표 프레임:** "한국형 포용(인프라) vs 개도국 해법(블록체인 건너뛰기)"
> 개도국은 은행은 없어도 폰은 있음 → 스테이블코인으로 **은행 단계 건너뛰기(leapfrog).**

## 7. 2장 마무리 — 신뢰의 진화 (★ 발표 클라이맥스)

신뢰를 **만드는 방법**이 3단계로 진화한다:

```
담보·관계  ───→  중앙은행 제도  ───→  블록체인 기술
 (사람)          (제도)              (기술)
전통은행          도매결제            비트코인/스테이블코인
                                          ↑
                          정부가 "여기 어디에 선 그을까" 고민
```

| 단계 | 신뢰를 어떻게 | 예시 |
|---|---|---|
| ① 전통 | 담보 잡고, 시간 들여 차입자 파악 | 주택담보, 신용카드 한도 |
| ② 중개기관 | 중앙은행이 은행 간 신뢰를 대체 | 은행 간 결제 시스템 |
| ③ 탈중앙 | 기관 없이 **투명성 + 불변성**으로 | 비트코인 블록체인 |

- 담보 = **행동 장치(commitment device)**: "못 갚으면 집 가져간다"로 갚게 만드는 강제
- 은행끼리도 100% 신뢰 ❌ → 중앙은행 결제 시스템이 상호 신뢰를 **대체**
- 비트코인 = 신뢰를 기관 대신 **공공(투명성·불변성)에 위임**

### ⭐⭐ 사용자의 핵심 통찰 — "기준선에 골머리 썩는 게 정부"

> 2장 = 현재 금융이 신뢰를 만드는 방식의 **기준선**.
> 새 기술이 이 기준선을 흔든다 → **나아질 부분**(국경결제·포용)과 **위험한 부분**(안정성·통제)이 갈린다.
> → 그래서 정부가 **"어디에 선을 그을 것인가"** 골머리. (= 디지털자산 2단계 법안, 준비자산 규제, CBDC)

### 그래프로 마무리 — 나아짐 🟢 / 위험 🔴

| 금융 기능 | 현재(기준선) | 블록체인이 오면 | 평가 |
|---|---|---|:---:|
| 국경 간 결제 | 느림·비쌈 | 빠름·쌈 | 🟢 |
| 금융포용 | 개도국 소외 | 폰으로 접근 | 🟢 |
| 신뢰·안정성 | 정부 보증 | 기술 의존 | 🔴 |
| 통제·감독 | 중앙 관리 | 분산·사각지대 | 🔴 |

## 2장 마무리 멘트

> 1장이 '변화가 온다'였다면, 2장은 **'그 변화를 잴 기준선'**을 그렸다.
> 핵심은 신뢰 — 금융은 신뢰를 **담보(사람) → 중앙은행(제도) → 블록체인(기술)**으로 만들어왔다.
> 새 기술은 이 기준선을 흔든다. 어떤 건 나아지고(결제·포용), 어떤 건 위험하다(안정성·통제).
> **그래서 지금 정부가 골머리를 썩는다 — '어디에 선을 그을 것인가.'**
> 그게 우리가 9주간 따라갈 이야기다.
