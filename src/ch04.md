# 4장. 혁명을 일으키고 주춤하는 비트코인

---
이 장은 **비트코인**이 왜 등장했고, 어떤 기술(블록체인·암호화·분산원장·작업증명)로 "은행 없는 신뢰"를 구현했으며, 어떤 한계에 부딪혔는지를 정리한다.

- 한 줄 요약: 비트코인은 **"신뢰를 기관이 아니라 기술로 보장한다"**는 발상의 산물이다.
- 목차: ① 등장 배경·목적 → ② 블록체인이란 → ③ 핵심 기술 → ④ 채굴·작업증명 → ⑤ 공급 구조 → ⑥ 장점과 한계

---

## 1. 비트코인의 등장 배경과 핵심 목적

### 등장 배경
- **2008년 글로벌 금융위기** 이후 은행과 정부에 대한 신뢰가 크게 흔들림.
- 익명의 **사토시 나카모토**가 "중앙기관 없이 개인 간 직접 거래가 가능한 전자화폐"를 제안.
- 비트코인은 **은행 없이도 거래할 수 있는 새로운 디지털 화폐**를 목표로 개발됨.

### 핵심 목적
- 개인 간 직접 거래(**P2P**)
- 거래 내역 **위·변조 방지**
- **이중 지불(Double Spending) 방지**
- **거래 신뢰성 확보**

> 핵심 철학: **신뢰를 기관(은행·정부)이 아니라 기술로 보장한다.**

---

## 2. 블록체인(Blockchain)이란?

> **모든 거래 내역을 여러 컴퓨터가 동시에 저장하는 분산 장부 기술.**

| 특징 | 의미 |
|---|---|
| **중앙 서버 없음** | 특정 기관이 장부를 독점 관리하지 않음 |
| **모든 참여자가 거래 내역 공유** | 누구나 같은 장부를 보유 |
| **데이터 위·변조 어려움** | 조작하려면 다수 참여자를 동시에 속여야 함 |
| **거래 기록 삭제 불가** | 한번 기록되면 되돌릴 수 없음 |

---

## 3. 비트코인의 핵심 기술

| 기술 | 역할 | 설명 |
|---|---|---|
| **공개키 / 개인키** | 은행 계좌와 비밀번호 | 공개키 = 계좌번호, 개인키 = 비밀번호 |
| **해시(Hash)** | 데이터의 디지털 지문 | 거래 정보를 짧은 코드로 변환. 내용이 조금만 바뀌어도 완전히 다른 값 생성 → **위변조 검증 가능** |
| **분산원장(DLT)** | 투명성·보안 | 모든 참여자가 동일한 거래 내역 보유. 중앙 장애점 없음, 해킹 어려움 |
| **머클트리(Merkle Tree)** | 효율적 검증 구조 | 수많은 거래를 효율적으로 검증. 빠른 검증·저장공간 절약·네트워크 부하 감소 |

## 4. 채굴(Mining)과 작업증명(PoW)

비트코인의 대표적인 **합의 알고리즘 = 작업증명(Proof of Work)**.

### 원리
1. 채굴자들이 수학 문제를 **경쟁적으로** 풂.
2. 가장 먼저 푼 사람이 **거래 블록 생성**.
3. 다른 노드들이 **검증**.

### 효과
- 위조 방지
- 이중 지불 방지
- 블록체인 보안 확보

### 코드로 보는 작업증명 (난이도 = 앞자리 0의 개수)

작업증명의 핵심은 **"해시값이 목표 조건(예: `0000`으로 시작)을 만족할 때까지 nonce를 계속 바꿔 다시 해시하는 것"**이다. 아래는 자바로 구현한 채굴 로직의 핵심.

```java
public static void main(String[] args) {
    // 난이도 4: 해시가 "0000"으로 시작할 때까지 nonce를 변경
    Blockchain blockchain = new Blockchain(4);
    blockchain.addBlock("A가 B에게 100원을 송금");
    blockchain.addBlock("B가 C에게 50원을 송금");
    blockchain.addBlock("C가 D에게 30원을 송금");
    blockchain.printBlockchain();
    System.out.println("블록체인 유효성: " + blockchain.isChainValid());
}
```

```java
// 블록 생성 — 이전 블록의 해시(previousHash)를 포함해 사슬로 연결
public Block(int index, String data, String previousHash) {
    this.index = index;
    this.timestamp = System.currentTimeMillis();
    this.data = data;
    this.previousHash = previousHash;   // ← 이 연결이 "체인"을 만든다
    this.nonce = 0;
    this.hash = calculateHash();
}
```

```java
// 작업증명(PoW) 채굴 — 목표 조건을 만족할 때까지 nonce++ 반복
public void mineBlock(int difficulty) {
    String target = "0".repeat(difficulty);   // 난이도 4 → "0000"
    while (!hash.startsWith(target)) {
        nonce++;
        hash = calculateHash();                // nonce가 바뀌면 해시도 완전히 달라짐
    }
}
```

> **포인트:**
> - 난이도(앞자리 0의 개수)가 올라갈수록 조건을 만족하는 nonce를 찾기가 **기하급수적으로 어려워짐** → "일(work)"을 증명.
> - 각 블록이 **이전 블록의 해시(previousHash)**를 품고 있어, 하나만 위조해도 뒤 블록들의 해시가 전부 어긋남 → **위·변조 즉시 발각**(불변성의 원리).

## 5. 비트코인 공급 구조

- **최대 2,100만 개** — 발행량이 고정되어 있음.
- **반감기**: 약 4년마다 채굴 보상이 **50% 감소**.
- **목적**: 희소성 유지 → 가치 하락 방지.

## 6. 블록체인의 장점과 비트코인의 한계

### 블록체인의 장점
| 특성 | 내용 |
|---|---|
| **신뢰성** | 중앙기관 없이 거래 가능 (탈중앙화 — 특정 기관이 통제하지 않음) |
| **투명성** | 모든 거래 기록 공개 |
| **보안성** | 위조·변조 어려움 |
| **불변성** | 한번 기록된 거래는 수정 불가 |

### 비트코인의 한계
| 문제 | 내용 |
|---|---|
| **가격 변동성** | 가치가 크게 오르내려 결제수단으로 부적합 |
| **거래비용** | 수수료 증가, 처리 속도 느림 |
| **확장성 문제** | 거래량 증가 시 성능 저하 |
| **법정화폐 대체 어려움** | 정부 보증 없음, 공급량 제한으로 경제 운영에 한계 |

> **⭐ 불변성의 양날 — "되돌릴 수 없고, 잃으면 못 찾는다"**
> 장점인 **불변성**이 곧 위험이 되는 지점.
> - **원복 불가**: 중앙기관이 없어 되돌려줄 주체가 없음 → 오송금·사기도 **취소(환불) 불가**. (은행 이체는 취소 가능)
> - **분실 = 영구 소멸**: 개인키를 잃으면 그 코인에 **영원히 접근 불가**. 전 세계 비트코인의 약 **20%(300만~400만 개)가 이미 분실**된 것으로 추정.
>
> → "기관 없는 자유"의 대가 = **모든 책임이 개인에게**. 안전망이 없다.

---

## 한 줄 정리

> 비트코인은 **"은행 없이도 신뢰할 수 있는 거래를 가능하게 하자"**는 목표로 탄생했으며, 이를 위해 **블록체인·암호화·분산원장·작업증명** 기술을 결합한 혁신적인 디지털 화폐다. 다만 **가격 변동성과 확장성 문제**로 인해, 현재는 결제수단보다 **투자자산(디지털 금)**의 성격이 더 강하다.
